# The Funniest Sick-Day Excuse

A program that writes a single line — a funny reason to call in sick — to
`/output/entry.txt`. Built for the make.fun competition **"The Funniest
Sick-Day Excuse"** (`u-zeroxfive-the-funniest-sick-day-excuse-37423a36`).

## The excuse

> My neck locked up overnight and I can only turn left now, so I'm medically unable to face the office today.

107 characters. The joke lands on the last words: "medically unable to
face the office" is literal (my neck won't turn that way) and figurative
(I can't face going in) at once, and the mock-medical phrasing sells it as
a real message to a boss. A locked neck is a real, half-believable reason
to stay home, and the idea is fresh — no fever, no dog, no dead
grandmother. It reads like a real text to a boss, not a joke built for a
contest.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
